# WriterTools 使用手册（v0.1.5）

用一句话说：**这是一个只会写字、但会把你写下的每个字（包括删掉的字）都留住的本子。**

---

## 1. 打开与安装

- 本机运行：`npm install` 后 `npm run build && npm run preview`，浏览器打开 **http://127.0.0.1:4173/**。
- 想装成应用：Chrome/Edge 地址栏右侧「安装」图标；安卓 Chrome 菜单 →「添加到主屏幕」。
- 同一套网页代码可在 Windows / macOS / Linux / 安卓的现代浏览器使用；数据保存在该浏览器本地。
- PWA 的 Service Worker 只在**生产构建**注册（`npm run build` + `npm run preview` 或部署后的站点）；`npm run dev` 不注册，避免缓存干扰开发。

## 2. 写作

| 操作 | 说明 |
| --- | --- |
| 新建作品 | 书架 →「新建作品」；标题默认「无题」，点左上角标题可改名（Esc 取消） |
| 输入 | 输入区始终在屏幕正中；当前光标行垂直居中 |
| 打字机模式 | 默认：每行从**右边缘**开始，向左侧生长；写满后内容上移一行，新行回到右边 |
| 居中模式 | 常规左对齐排版，光标行依然垂直居中；右上角按钮或设置里切换 |
| 保存版本 | `Ctrl+S`（macOS `⌘S`）→ 立即生成一个快照版本；快捷键可在设置里改成任意组合 |
| 返回书架 | `Esc`（有弹层/确认框时先关闭弹层） |
| 字号 / 行宽 | 设置 → 写作（14–32px；20–60em） |
| 主题 | 默认跟随系统明暗；可手动选浅色/深色；浅色背景可选纯白或奶白 |
| 自动保存 | 不需要点保存：每次输入、删除都会即时写入本地日志 |
| 原始输入回看 | 编辑器右上角的「原始输入」图标：按时间线查看拼音/候选过程、上屏文字、每次输入/删除/替换（含被删内容），支持播放、单步和查看原始事件 JSON；只读作品也能看 |

> 所有输入操作（包括输入法拼音过程，如果开启记录）都会写进日志；删掉的文字也会保存在删除事件里。想看这些记录的样子，点编辑器右上角的「原始输入」按钮。

## 3. 书架、版本与回收站

- **书架**：列出全部作品，显示标题、更新时间、字数、版本数。点作品打开，右侧图标可导出 `.wtlog` 或移入回收站。
- **版本历史**（编辑器右上角时钟图标）：列出快照（时间、说明、字数），点条目可预览正文，也可一键恢复。恢复本身也会作为新事件追加，旧历史永不丢。
- **回收站**：删除是**软删除**，日志和内容都保留；可在书架「回收站」里恢复。
- **导入**：支持 `.wtlog` / `.jsonl`（单篇）和 `.wtzip`（整库备份包）；若同一个 `docId` 已存在，不会覆盖现有作品。

## 4. 你的数据在哪里（重要）

| 层 | 位置 | 作用 |
| --- | --- | --- |
| 主存储 | 浏览器 IndexedDB（库 `writertools`） | 每次输入实时追加事件，刷新/重启浏览器后仍在 |
| 冗余镜像 | 浏览器 OPFS（源私有文件系统） | 冗余副本，启动时自动扫描并补回主存储缺失 |
| 备份目录 | 你选择的真实文件夹（桌面 Chromium / Android App） | 自动写真实 `.wtlog` + 校验清单，可在浏览器之外长期保存 |
| 全量备份包 | 你下载的 `.wtzip` | 单文件整库备份，可放到网盘/U 盘/另一台电脑 |

### 4.1 建议的备份策略（两分钟设置一次，之后不用管）

1. 设置 → 数据安全 → **选择备份目录**，指向一个真实文件夹（最好选会自动云同步的文件夹，如 OneDrive/坚果云/Nextcloud 的本地同步目录）。Android App 里会打开系统文件夹选择器，选择一个可写文件夹并点「允许」即可。
2. 之后每次保存版本、关闭作品、应用启动时都会自动备份（约 3 秒防抖、最小间隔 15 秒）。
3. 设置里能看到「已配置 · 上次备份 时间」；失败会显示错误但不会打断书写。
4. 另外建议偶尔导出一次 `.wtzip` 放到浏览器之外（网盘/U 盘），多一层保险。

### 4.2 如果浏览器数据丢失了怎么办

1. 打开应用（书架可能是空的）；
2. 设置 → 数据安全 → 重新**选择同一个备份目录**；
3. 点「**从备份目录恢复**」；
4. 应用会逐个校验磁盘上的 `.wtlog`，把作品恢复到书架（只追加、不覆盖更新副本、分歧只报告）。

如果连备份目录也没有了：用之前导出的 `.wtzip` → 设置 →「从备份包恢复」。

### 4.3 其它恢复机制

- **启动自动恢复**：每次打开应用会后台扫描 OPFS 镜像，主存储事件缺失/被截断时自动补回并提示「已从镜像恢复 N 个作品」。
- **校验全部**：设置 → 数据安全 →「校验全部」，检查全部作品的哈希链与快照一致性。
- **导出诊断文件**：单篇作品右侧下载图标导出 `.wtlog`；可用 `npm run check:log -- 文件.wtlog` 独立校验。

### 4.4 Android App（APK）说明

- **安装**：手机微信/文件管理器里打开 APK → 允许安装未知应用；首次启动即可用。
- **数据位置**：App 有自己的 WebView 沙盒（IndexedDB + OPFS），重启 App 仍在；**卸载 App 会清空沙盒数据**。
- **备份目录**：设置 → 数据安全 →「选择备份目录」会打开 Android 系统文件夹选择器；选择一个文件夹并点「允许」。授权会被系统持久保存，重启 App 不需要重选（除非你撤销权限或卸载重装）。
- **灾备恢复**：数据丢失/卸载重装后，重新选同一个备份目录，点「从备份目录恢复」即可；备份目录里的 `writertools-manifest.json` + `*.wtlog` 是真实文件，换机/拷到电脑也能用。
- **暂不支持**：APK 内 WebView 的下载导出（`.wtzip`、单篇 `.wtlog`）暂不可用；需要导出时用浏览器版，或把备份目录里的文件直接拷出来。

## 5. 设置说明

- **外观**：主题（跟随系统/浅色/深色）、浅色背景（纯白/奶白）。
- **写作**：默认排版模式、字号、行宽、是否记录输入法原始过程（关闭后仍完整记录最终上屏文字与删除操作）。
- **快捷键**：保存快照快捷键可自定义（需含 Ctrl / Alt / ⌘ 组合）；Esc 固定为返回/关闭。
- **数据安全**：持久化存储状态、用量/配额、OPFS 镜像状态、备份目录（选择/立即备份/自动备份状态/从备份目录恢复；桌面浏览器用文件夹授权，Android App 用系统文件夹选择器）、导出全部备份包、从备份包恢复、校验全部、扫描恢复。

## 6. 常见问题

**Q：软件里看不到"文件"？**
数据主存是浏览器本地数据库；真实文件来自「备份目录」或「导出」。建议按 4.1 设置一次备份目录。

**Q：为什么日志文件越来越大？**
因为记录的是完整历史（包括删掉的每个字、每次输入法过程）。这是刻意的：为了"可追回"和训练分身。后续版本会提供压缩（生成新文件，保留原件）。

**Q：多开标签页会怎样？**
同一作品同一时间只允许一个标签页写入；另一个标签页以只读打开，顶部会提示。

**Q：换电脑/换浏览器怎么办？**
导出 `.wtzip` 或选备份目录，在新环境里导入/恢复；`docId` 不变，作品身份保持一致。

**Q：数据会加密吗？**
当前版本是明文 JSON Lines（本地文件），**没有加密**。请不要把日志/备份上传到不可信服务。

**Q：怎么把写作记录拿去做训练？**
见 [TRAINING-DATA.md](TRAINING-DATA.md)：`npm run export:training -- <文件或目录> --out training.jsonl`。

**Q：支持哪些平台？**
Web/PWA：Windows/macOS/Linux 的 Chrome/Edge，以及安卓 Chrome。桌面原生安装包（.exe/.dmg/AppImage/APK）属于后续计划。

## 7. 安全边界（请知悉）

- 能防：意外损坏、误删、部分数据丢失、单点篡改（哈希链）、截断/重写（备份清单锚点）。
- **不能防**：拥有本机完全控制权的恶意程序；浏览器/系统主动清除站点数据且你没有任何外部备份的情况；忘记设置备份目录又不导出。
- 所以：**请至少设置一次备份目录，或定期导出 `.wtzip` 到浏览器之外。**
